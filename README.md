# 腓骨瓣重建规划与截骨导板设计系统

浏览器内完成：CT 分割模型（STL/PLY）导入与体检修复 → 下颌骨切除规划 → 腓骨瓣分段排布 →
图像空间 CSG 导板设计（深度剥离 + 模板）→ 精度校核 → 水密 STL 导出送院内打印 + 规划单。

- **技术栈**：TypeScript + 原生 WebGL2/GLSL（无 Three.js），IndexedDB 持久化病例与模型
- **纯函数几何核心**（`src/core`）不依赖 DOM/WebGL，可用 Vitest 在 Node 中直接验证精度

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # 精度/拓扑/排布测试（约 70s，含体素重建与 STL 端到端校核）
npm run build      # 类型转译 + 生产打包到 dist/
npm run preview
```

首次启动自动播种两例病例（左/右下颌肿瘤），其中右侧病例的腓骨是**带破洞 + 翻转面**的测试模型，
会在“模型导入”页看到完整体检与自动修复报告。也可用页面按钮装入内置模型或导入真实 STL/PLY。

## 七个页面

| 页面 | 对应需求 |
| --- | --- |
| 病例列表 | 肿瘤分期、Brown 分类、取左/右腓骨、血管蒂方向；一病例多方案 + 并排指标比较 |
| 模型导入 | STL/PLY 解析；破洞/非流形边/翻转法线/退化面检查；可修复项自动修复并标记，过大洞/非流形拒收并指明哪块模型 |
| 切除规划 | 2–4 个截骨平面，视口拖拽沿法线移动、滑杆旋转；距肿瘤 < 安全边界标红；神经管交点高亮 |
| 腓骨排布 | 缺损弧长自动分段、长度 + 两头楔形角；<20mm 拦截、远端 6cm 保踝；接缝缝隙彩色接触斑；拖拽段时邻段重新对准、楔形角重算；颏部/下颌角/RMS 偏差实时 |
| 导板设计 | 下颌/腓骨导板；贴骨偏移底板、锯槽（锯片厚度+间隙）、钉孔；**深度剥离两遍 + 模板覆盖 + 片元剔除**的实时图像空间 CSG；就位方向倒凹标红并可自动削除 |
| 校核导出 | 导出 STL 反拟合锯槽平面的夹角/偏移表；锯片扫查神经管与对侧皮质；预览基准 vs 导出 STL 轮廓偏差；水密/流形/自交/壁厚强制校验，不合格锁定 STL；HTML 规划单（含长度/楔角/截图，可打印 PDF） |
| 设置 | 锯片厚度、槽间隙、钉孔直径、导板壁厚、安全边界、打印机精度；变更后旧导板提示重算 |

## 精度是怎么保证的（最在意的锯槽）

1. 锯槽由规划平面的**精确解析 SDF 盒**定义，体素 SDF + 插值移动四面体重建出水密流形网格；
2. 导出前 `snapSlotWalls` 按法向 + 距离窄带选中槽壁三角形，把壁面顶点投影到
   `平面锚点 ± 槽宽/2` 的**精确数学平面**；共享顶点一起移动，不破坏水密；
3. 写出二进制 STL 后**重新解析 STL**，用 Newell 法反拟合两面槽壁、取中心面，
   与规划平面算夹角/偏移——端到端验证，而非只看内存网格。

`test/accuracy.test.ts` 的实测断言（默认参数，毫米/度）：

```
下颌截骨平面 1  angle ≈ 0.00–0.11°   offset ≈ 0.000 mm
下颌截骨平面 2  angle ≈ 0.00–0.30°   offset ≈ 0.000–0.005 mm
断言：夹角 < 0.5°，偏移 < 0.3mm
```

轮廓偏差：导出 STL 采样点到精修前体素 CSG 基准的距离，典型 **P95/RMS ≈ 0.01mm**，
按 `P95 ≤ 打印机精度(默认0.1mm)` 且 `max ≤ 3×精度` 放行。

## 导出几何路线

需求允许“真正的网格布尔**或**体素重建”。主导出路径是**体素 SDF 重建**
（`src/core/voxel.ts`：骨板距离喷溅 → 6 邻接外部泛洪定内外 → SDF 减法合并锯槽/钉孔 →
插值移动四面体 + 全局边缓存），天然输出 0 边界边 / 0 非流形边的水密网格。
另有一份 BSP CSG 实现（`src/core/csg/bsp.ts`）用于理解/对照真实网格布尔。
